# QuartoLectureNotesTemplate

This is a template repo for accessible Quarto lecture notes, developed at the University of Warwick. The files provided give a minimal structure which should allow for the development of parallel html and pdf output.

Within the project:
- `src` provides source files, including quarto markdown files, `*.qmd`, and the critical YAML header, `_quarto.yml`.
- `docs` holds the output from rendering as things are currently set up.
